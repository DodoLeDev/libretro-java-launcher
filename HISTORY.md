# Change Log
All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](http://keepachangelog.com/)
and this project adheres to [Semantic Versioning](http://semver.org/).

## 2.0.0 - Libretro Core, new gener(aliz)ation
 - The whole core has been rewritten to be configured with **any single program you want**! No more java-launcher here, wine-launcher there! Everything can be handled by the same core.

## 1.0.0 - A new story begins
